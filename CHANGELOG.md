# Changelog

Each release is tagged `v<version>`. Releases before 1.1.0 were made from
[flowon-official/ai-plugins](https://github.com/flowon-official/ai-plugins) (then named claude-plugins), tagged
`flowon-dynamics-v<version>`; this repository keeps their history and tags them `v<version>`.

## 1.1.0 (2026-11-24)

- The plugin installs in Codex and GitHub Copilot from the same marketplace, and its skill names the AI tool neutrally.

## 1.0.2 (2026-11-23)

- Connection strings stay out of the conversation: the skill never asks for one or shows one.

## 1.0.1 (2026-11-20)

- Troubleshooting: `import` in version 1.2.0 of the tools needs `--solution-timeout`.

## 1.0.0 (2026-11-20)

- The Logic Fabric CLI skill for Claude Code: commands, file formats and the safe way to deploy.
